Mini-Inventory

add / edit / delete / search / export

How it was built & how to use it

Where I use it

I wrote this for my Loss Prevention work at CRC Thai Watsadu, to record lost and damaged goods (item name, SKU, quantity and price) in one searchable list.

How it was built

  • A single-page app in plain HTML, CSS and JavaScript. No framework and no server.
  • Records are kept as a JSON list in the browser's localStorage, so they are still there after a refresh or after closing the tab.
  • Every change calls render(), which filters (by name or SKU), sorts and redraws the table.
  • Separate functions add, edit and delete a record, save it, and redraw. Text is escaped before it is shown, so typed text cannot inject HTML.
  • Export builds a CSV text and downloads it as a file with a Blob.

How to use it

  1. Open the project. Type the product name, SKU, quantity and price, then press Add / Update.
  2. Type in Search to filter by name or SKU. Click a column title to sort A→Z or Z→A.
  3. Press Edit to load a row back into the form, change it, then press Update. Delete asks you to confirm first.
  4. Press Export CSV to download inventory.csv. Clear All removes every record.

Data stays in the browser on the device you use and is never sent anywhere. The first three rows (Box A, Tape, Bubble Wrap) are sample data, so press Clear All to start fresh.

Calm Sound

Music therapy for low mood: mood check-in, generated calming sounds, guided breathing, sleep timer and mood log

How it was built & how to use it

A self-care tool, not medical treatment. It cannot diagnose or treat depression. If you feel unsafe, call the Thai Mental Health Hotline 1323 or emergency services 1669.

How it was built

  • One HTML file with plain CSS and JavaScript. No framework, no server and no audio files.
  • The sounds are made live in the browser with the Web Audio API. Warm Pad and Soft Bells use oscillators (the bells play random notes from a pentatonic scale through an echo). Rain and Ocean use filtered noise, and the ocean's volume is slowly swelled by a low-frequency oscillator.
  • Because the sound is generated, there is no copyright issue and the page loads quickly.
  • The mood check-in maps each of five moods to a starting sound and breathing pattern. You can change both at any time.
  • The breathing guide runs a timer loop of phases (in, hold, out). It animates a circle, shows a countdown and can raise and lower the volume in time with your breath.
  • The sleep timer counts down, then fades the sound out.
  • The mood log is saved in localStorage and drawn as an SVG line chart, with average mood and minutes listened. Notes are inserted as plain text.

How to use it

  1. Pick the face that matches how you feel. The page suggests a sound and a breathing pattern.
  2. Press Play (the browser only allows sound after a click). Change the sound or volume, and choose a sleep timer if you want one.
  3. Press Start breathing guide and follow the circle: it grows as you breathe in and shrinks as you breathe out.
  4. Add an optional note and press Save today's mood. The chart appears once you have two entries.
  5. Use Export CSV to keep a copy of your log, or Clear log to delete it.

Everything stays on your device. Headphones and a low volume work best.
